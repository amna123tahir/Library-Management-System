# Library Management System (C++)

##  Description
A text-based Library Management System built in C++ using file handling.

##  Features
- Add Book
- Display Books
- Search Book
- Issue Book
- Return Book

##  File Handling
Uses binary file storage (`library.txt`) to store book records.

## Technologies Used
- C++
- File Handling (fstream)

##  How to Run
1. Compile:
   g++ main.cpp -o library
2. Run:
   ./library
